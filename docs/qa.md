# QA 체크리스트

실기기에서만 확인 가능한 항목은 📱.

## 시작
- [ ] 첫 실행: 스플래시 → 온보딩 1 → 2 → 지도 홈
- [ ] 두 번째 실행: 스플래시 → 지도 홈
- [ ] 온보딩 "나중에 할게요" → 지도 홈에 위치 꺼짐 배너, 핀 추가 비활성

## 지도 홈
- [ ] 모두의 마당 / 내 마당 토글 시 핀 색·개수 바뀜
- [ ] 내 마당에 핀 0개 → 빈 마당 화면
- [ ] 줌 아웃 시 가까운 핀이 숫자 뱃지로 묶임
- [ ] 묶음 탭 → 목록 카드, 항목 탭 → 상세 카드
- [ ] 📱 현재 위치 버튼 → 내 위치로 이동
- [ ] 네트워크 끊김 → 검은 배너, 내 핀은 보임

## 심기
- [ ] 📱 핀 추가(권한 없음) → 권한 안내 화면 재사용
- [ ] 📱 녹화 버튼 길게 → 링 차오름 → 1.5초 후 미리보기
- [ ] 📱 1.5초 전에 손 떼면 녹화 취소, 안내 문구
- [ ] 📱 카메라 거부 상태 → "설정 열기" 화면
- [ ] 미리보기 다시 찍기 → 녹화로, 이걸로 할게요 → 위치 확인
- [ ] 📱 위치 확인: 지도 이동 시 말풍선 주소 갱신(300ms 디바운스)
- [ ] 위치 확인: 내 핀 20m 안 → "지난번 자리 근처예요", 더하기/새 자리
- [ ] 위치 확인: 주소 못 찾음 → 안내 + 자리 이름 강조, 다음으로 진행 가능
- [ ] 메모: 자리 이름 16자, 메모 100자, 차 10자, 태그 5개 제한
- [ ] 저장: 버튼이 진행 바로, 뒤로 가기 비활성
- [ ] 저장 실패(오프라인) → 나중에 올리기 → 연결 시 자동 업로드
- [ ] 저장 완료 카드 매번 표시 → 자리 보기 / 지도로

## 상세 카드
- [ ] 핀 탭 → 카드 펼침, 영상 자동 재생(무음, 반복)
- [ ] 지도 드래그·탭 → 카드 접힘(띠), 띠 탭 → 펼침, 띠 아래로 → 닫힘
- [ ] 좌우 스와이프 → 모두: 거리순 / 내 마당: 최근순, 지도 따라 이동
- [ ] 카드 위로 끌기 → 영상 전체 화면
- [ ] 길 찾기 → 네이버지도 열림
- [ ] 내 핀: 이 자리 지우기 → 확인 카드 → 삭제
- [ ] 남의 핀: 신고하기 → 사유 선택 → 내 지도에서 사라짐
- [ ] 같은 자리 여러 번 심은 핀: 다른 날 썸네일 + "+"

## 설정
- [ ] 계정 연결: 카카오 / Apple(iOS만) → 익명 핀 유지
- [ ] 계정 삭제: 체크 두 개 켜야 버튼 활성 → 삭제 후 온보딩으로
- [ ] 약관·개인정보 페이지 열림

## 접근성
- [ ] VoiceOver로 지도 홈 모든 버튼에 이름 읽힘
- [ ] 상세 카드 접근성 액션으로 다음/이전 자리 이동
- [ ] 모든 탭 영역 44px 이상
- [ ] 글자 크기 키워도 레이아웃 안 깨짐
